## Product guardrails

- One location only for MVP.
- Web only for MVP; native mobile is deferred.
- Roles are owner, coach, and customer.
- Modular monolith; no microservices or speculative distributed architecture.
- Next.js 16, React 19, TypeScript, Prisma, PostgreSQL, pnpm, Turborepo.
- Stripe is the payment provider for current billing slices.
- Email only at launch.
- Do not introduce multi-location assumptions.

## Working rules

- Work only from an explicit, scoped request or work packet.
- Keep changes small and inside the current slice.
- Use tests for behavior-changing work. Run the relevant local gates and report real output.
- UI work requires screenshot evidence at relevant desktop/tablet/mobile widths.
- Use isolated branches/worktrees for implementation; never overwrite unrelated local changes.
- Do not deploy, push remote changes, contact customers/prospects/vendors, use production credentials, or make pricing/product/market commitments without Jacky's explicit approval.
- Keep secrets out of docs, screenshots, logs, and commits; represent credentials as `[REDACTED]`.
- Reports lead with plain-English outcome, why it matters, blockers, and next action. Put commands, paths, logs, screenshots, and commit IDs under `Evidence / technical details`.
