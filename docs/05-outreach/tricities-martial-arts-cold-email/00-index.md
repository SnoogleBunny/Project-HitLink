# Tri-Cities Martial Arts Cold Email

Use this folder for the first small-batch Flowstate outreach list in Coquitlam, Port Coquitlam, and Port Moody.

Files:

- [[01-prospect-list]] - gym names, public emails, owner or decision-maker notes, and verification status.
- [[02-cold-email-drafts]] - text-only cold email drafts and follow-ups.
- [[03-send-plan]] - domain, deliverability, cadence, and daily workflow.

Working rule: do not blast this list. Research each gym, verify the email before sending, customize the first line, and keep each thread to three touchpoints max.

Excluded for now:

- Advantage Fitness - scratched because the current focus is Tri-Cities, not Burnaby.
