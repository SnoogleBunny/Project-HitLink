# MVP Scope Brain

Use this note when deciding whether something belongs in the first sellable demo.

## In MVP

- Owner signup and workspace onboarding.
- Admin shell and navigation.
- Programs and rooms.
- Weekly recurring schedule templates.
- Bookings, roster, attendance.
- Member profiles, notes, tags, guardians.
- Public trial booking.
- Member portal access.
- Member schedule browsing and class booking.
- Membership plans.
- Member memberships.
- Punch cards and drop-ins.
- Billing state and failed-payment workflows.
- Stripe settings and webhook endpoint.
- Forms, versions, required assignments, signature requests, signed documents.

## Demo-Ready But With Known Limits

- API app is health-check only.
- Staff invites are records only; email delivery and acceptance are not complete.
- Stripe-dependent flows need real Stripe credentials.
- Forms are PDF/version/signature-record based, not a full visual PDF editor.
- Class instances are mostly derived from templates and dates, not fully persisted one-off schedule operations.

## Deferred

- Multi-location.
- Native mobile.
- SMS/push.
- Marketplace integrations.
- Events and private lessons.
- Deep reporting.
- Migration tooling beyond current schema/planning docs.
- Rich messaging/broadcast automation.
- Full coach invite acceptance UX.
