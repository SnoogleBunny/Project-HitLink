# Customer And ICP

## Primary Customer

The owner/operator of a single-location Muay Thai gym or Hyrox/HIIT-style class studio.

## Buyer Pain

- Current tools feel clunky.
- Scheduling and attendance are annoying.
- Billing state is hard to trust.
- Member self-service is weak.
- Migration risk keeps owners stuck.

## Users

### Owner

Sets up the business, manages schedule, members, forms, billing, staff, and migration.

### Coach

Uses roster and attendance workflows. Coach dashboard is intentionally narrower than owner admin.

### Customer

Uses the member portal to book, view bookings, see membership/billing, and complete forms.

## Buyer Confidence Moments

- Owner can create a workspace without help.
- Owner can create schedule data and immediately see it in member portal.
- Member can book from the portal.
- Owner can see that booking in roster.
- Billing state is understandable even before live Stripe is connected.
