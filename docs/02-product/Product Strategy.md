# Product Strategy

## Thesis

HitLink replaces old gym-management tools with a calmer operating system for class-based gyms.

The wedge is not "more features than Zen Planner." The wedge is that the core daily loops feel reliable, understandable, and demoable:

- Owner creates schedule and manages operations.
- Coach sees roster and marks attendance.
- Member books classes and understands billing/forms.
- Billing state is visible and actionable.
- Migration feels trustworthy.

## Primary ICP

- Muay Thai gyms.
- Hyrox/HIIT-style class studios.
- Single-location boutique class gyms with similar scheduling and billing needs.

## Not The First ICP

- Multi-location groups.
- Franchise systems.
- Retail-heavy gyms.
- Enterprise chains.

## Differentiation

- Better UX.
- Reliable daily workflows.
- Migration-friendly onboarding.
- Clear member self-service.
- Fewer operational surprises.

## Sales/Demo Promise

"You can run tomorrow's schedule, take bookings, manage members, see billing state, and give members a portal without the system feeling like a chore."
