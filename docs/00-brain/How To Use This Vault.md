# How To Use This Vault

Use this vault as the durable brain for Flowstate. Every meaningful product, business, or technical decision should land here.

## Decision Rule

When a decision changes product behavior, business model, customer promise, data model, pricing, implementation direction, or demo readiness, add it to [[01-decisions/Business Decision Log]].

For larger decisions, duplicate [[01-decisions/Decision Record Template]] into `01-decisions/` and link it from the log.

## Working Memory Rule

Use [[99-inbox/Open Inputs Needed From Jacky]] for anything that cannot be decided from code or current docs.

Use [[04-demo/Working Demo State]] after each audit or demo-prep pass.

Use [[02-product/MVP Scope Brain]] when a request risks expanding MVP scope.

## Tags

- `#decision` for decisions.
- `#open-question` for unresolved inputs.
- `#demo` for demo readiness.
- `#scope` for MVP and roadmap boundaries.
- `#technical` for engineering architecture or implementation constraints.
