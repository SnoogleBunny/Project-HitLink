# Demo Script

## 1. Owner Admin

1. Open http://localhost:3000.
2. Log in as demo owner or create a new owner account.
3. Show workspace dashboard.
4. Open Programs and Rooms.
5. Open Schedule and show a weekly class template.
6. Open Members and show Demo Member.
7. Open member billing and show membership/punch-card state.
8. Open Today roster and show the booked class.

## 2. Member Portal

1. Open http://localhost:3001/login.
2. Log in as demo member.
3. Show overview, membership, and billing.
4. Open Schedule.
5. Book an available class.
6. Open Bookings and show active booking.

## 3. Public Trial

1. Open the public trial URL for a workspace.
2. Show class-date selection and participant fields.

## 4. Honest Disclaimers

- Stripe is wired conceptually but needs real credentials for live checkout/payment-method flows.
- Staff invite email delivery and acceptance are not complete.
- API is currently a health endpoint, not a public integration API.
