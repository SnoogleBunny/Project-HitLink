# Flowstate Agents

Flowstate uses eleven durable Hermes profiles. They share model/tool configuration and skills with the established Amber roles, but have separate identity, memory, sessions, schedules, and project context.

## Profile map

| Role | Profile | Launch |
|---|---|---|
| CEO | `hitlink-ceo` | `hermes -p hitlink-ceo chat` |
| Kanban Orchestrator | `hitlink-orchestrator` | `hermes -p hitlink-orchestrator chat` |
| BA Sales | `hitlink-ba-sales` | `hermes -p hitlink-ba-sales chat` |
| Backend | `hitlink-backend` | `hermes -p hitlink-backend chat` |
| Frontend | `hitlink-frontend-dev` | `hermes -p hitlink-frontend-dev chat` |
| Database | `hitlink-db` | `hermes -p hitlink-db chat` |
| QA | `hitlink-qa` | `hermes -p hitlink-qa chat` |
| Gym Workflow | `hitlink-workflow` | `hermes -p hitlink-workflow chat` |
| Localization Content | `hitlink-localization` | `hermes -p hitlink-localization chat` |
| Design Continuity | `hitlink-design` | `hermes -p hitlink-design chat` |
| UX Lead | `hitlink-ux` | `hermes -p hitlink-ux chat` |
